## Decisiones tomadas

- `update` solo permite editar patrones que aún no han comenzado; para cambiar un patrón activo se crea uno nuevo y se archiva el anterior.
- `rename` permite cambiar el nombre sin tocar días ni fechas.
- `archive` fija `endDate` antes de `archivedAt`; así el histórico sigue resolviéndose.
- El solapamiento se comprueba contra todos los patrones del usuario, no solo los activos, para no reescribir fechas pasadas.
- La query de calendario limita el rango a 366 días y usa `Europe/Madrid` si el usuario no tiene zona válida.
- El motor no devuelve propiedades con `undefined` para que el resultado sea serializable por Convex.
