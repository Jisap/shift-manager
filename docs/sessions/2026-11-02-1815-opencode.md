# Sesión 2026-11-02 18:15 — opencode (deepseek-v4.1-flash-free)

## Objetivo

Responder a la necesidad de los usuarios de contabilizar horas extras y festivos trabajados (mejor pagados que las extras) y sentar la base de festivos.

## Decisiones de producto

- Solo se clasifican y cuentan horas; no se calculan importes ni multiplicadores.
- Si un día es festivo y además extra, se contabiliza como festivo-extra (sin sumar recargos).
- El usuario define los festivos manualmente con su ámbito.
