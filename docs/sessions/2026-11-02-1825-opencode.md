# Sesión 2026-11-02 18:25 — opencode (deepseek-v4.1-flash-free)

## Objetivo

Permitir que el usuario declare explícitamente horas extra sobre el turno planificado, indicando cuántas y en qué horario.

## Decisiones de producto

- Las horas extra no se detectan automáticamente: el usuario marca que las hizo y define los tramos.
- Cada tramo tiene hora de inicio y fin locales (`HH:mm`); el total lo calcula el backend con la zona horaria del usuario.
- Se pueden declarar hasta 4 tramos, sin solapamientos y con un máximo de 24 h por día.
- Si el día es festivo, la UI indica que se contabilizará como festivo-extra.
