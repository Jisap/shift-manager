## Objetivo

Eliminar del dashboard la representación negativa de la diferencia entre horas
previstas y reales. El panel debe mostrar trabajo ya realizado y usar los
términos acordados: **previsto** = horas de los turnos; **exceso** = horas
extra sobre esos turnos. Aplicar el mismo criterio a la exportación CSV/PDF.

## Hecho

      transcurridos (`day.date <= hoy`), aunque el filtro abarque el futuro.
- [x] Sustituida la tarjeta "Diferencia" por "Exceso", que muestra las horas
      extra registradas sobre los turnos (`overtimeMinutes`). Nunca es negativo.
- [x] Eliminada la tarjeta duplicada "Horas extra", porque mostraba el mismo
      dato que "Exceso".
- [x] El rango mostrado indica "· hasta hoy" cuando el periodo llega al futuro.
- [x] Exportación CSV/PDF: columna/celda "Exceso" con las horas extra sobre el
      turno; se elimina la columna duplicada "Horas extra".
- [x] Tests de CSV ajustados para comprobar que "Exceso" es la hora extra.

## Decisiones tomadas

- "Previsto" son las horas de los turnos; "exceso" son las horas extra sobre
  esos turnos. No se usa la diferencia neta (real + extra − previsto) para la
  interfaz porque mezcla déficits y trabajo pendiente.
- La diferencia con signo se conserva en el modelo (`differenceMinutes`) para
  uso interno, pero el dashboard y las exportaciones muestran "Exceso".
- El periodo se acota a hoy en la capa de datos del dashboard (no se cambia el
  rango del filtro ni la consulta a Convex).
